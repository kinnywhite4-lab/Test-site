NovaVest frontend V5 demo

Changes included:
- VIP-only Products page now has a My Products button at the top right.
- VIP purchases are recorded in browser localStorage and displayed on a dedicated My Products page.
- Purchase records show product, price, cycle, daily income, total revenue, purchase date and active status.
- Demo deposit now records a completed deposit and increases demo deposit balance so product purchases can be tested.
- Transaction, deposit and withdrawal histories now use a consistent full-width vertical record layout with icon, details, date/reference, amount and status.
- Withdrawal demo records pending withdrawals and deducts the available withdrawal balance.
- All financial values remain demo/configurable frontend behavior and are not a secure backend.
