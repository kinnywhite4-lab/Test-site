# NovaVest Investment Platform — V1

This is the first front-end prototype.

## Files
- index.html — app structure
- style.css — responsive mobile-first design
- script.js — navigation and demo interactions

## Run locally
Open `index.html` in a browser.

## Deploy
Push these files to a GitHub repository, then connect the repository to Netlify.

## Important
Demo balances and product values are placeholders. Replace them with verified platform data before using the application for real users.
